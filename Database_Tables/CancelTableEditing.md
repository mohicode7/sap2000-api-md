# CancelTableEditing

## Syntax

cDatabaseTables<a id="LST9389C294_01"></a>.CancelTableEditing

## VB6 Procedure

Function CancelTableEditing As Integer

## Parameters

## Remarks

Clears all tables that were stored in the table list
using one of the SetTableForEditing... functions.

Returns 0 if the function executes correctly, otherwise
returns nonzero.
